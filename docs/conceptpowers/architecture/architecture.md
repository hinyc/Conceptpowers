# 아키텍처

<!-- 사용자가 직접 작성: 개념의 상위 기준 -->

개념이 되지 못한 규칙이 모이는 자리다. 개념 자격 기준(`concept-scope`)의 두 테스트를
통과하지 못한 것 — 약속을 지키는 방법(기법)과 화면 요소의 생김새 — 을 여기에 적는다.
여기 적힌 것은 커밋 게이트가 강제하지 않는다. 개념이 정한 약속을 어떻게 지킬지에 대한
합의일 뿐이다.

## 화면 표기

### 상세 화면의 별칭 줄

개념 `concept-aliases`가 "별칭이 있으면 정식 이름 아래에 별칭이라고 밝힌 채 보여준다"를
약속으로 정한다. 그것을 **어떻게 그릴지**는 개념이 아니라 여기서 정한다.

- 자리: 제목 바로 아래, 요약보다 위
- 표기: `별칭 : 오징어, 바나나` — 이름표 뒤에 쉼표로 잇는다
- 크기: 본문보다 작게
- 색: 빨강 계열

빨강을 쓰되 상태 신호등의 빨강(`미승인`)과 같은 값을 쓰지 않는다. 같은 빨강이면 별칭이
달린 개념이 미승인으로 잘못 읽힌다. 뜻을 나르는 것은 `별칭 :`이라는 글자이고 색은 거들
뿐이라, 색을 못 보아도 읽는 데 지장이 없다.
