## 뷰어 서버

- 개념 확정을 물을 때 쓰는 링크 명령(`viewer-link`)은 이 프로젝트의 뷰어가 떠 있으면 다시 쓰고, 없으면 따로 떼어 낸 프로세스로 자동 실행한다
- 이렇게 자동 실행할 때는 브라우저를 열지 않는다. 사람이 링크를 눌러 연다 (`concepts:view`로 직접 실행하면 지금처럼 브라우저가 열린다)
- 자동 실행한 뷰어는 시간이 지나도 스스로 꺼지지 않고, 사용자가 `viewer-stop`으로 끌 때까지 유지된다. `viewer-stop`은 이 프로젝트의 뷰어만 끈다
- 포트는 4173~4192를 앞에서부터 쓰고, 이미 쓰이거나 권한이 없는 포트는 건너뛴다. 모두 쓸 수 없으면 이유를 알린다
- 프로젝트는 폴더의 실제 경로로 만든 식별값으로 구별한다. 상태 응답에는 식별값과 이름만 싣고 전체 경로는 싣지 않으며, 식별값이 다른 뷰어는 다시 쓰거나 끄지 않는다. 끌 때는 프로세스에 직접 신호를 보내지 않고, 이 컴퓨터 안에서 그 뷰어에 종료를 요청한다
- 서버는 이 컴퓨터 안(`127.0.0.1`)에서만 열리고, 이 컴퓨터 주소로 온 요청만 받는다
